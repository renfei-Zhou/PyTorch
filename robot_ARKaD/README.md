## 一句话总纲

整门课在造**一条从"关节数字"到"末端行为"的双向翻译链**，逐层加导数：

| 层 | 正向 | 反向 | 章 |
|---|---|---|---|
| 位置层 | `x = k(q)` | `q = k⁻¹(x)` | Ch3 / Ch4 |
| 速度层 | `ẋ = J(q)·q̇` | `q̇ = J⁻¹·ẋ` | Ch5, Ch6 |
| 力/加速度层 | `τ = M q̈ + C q̇ + g` | `q̈ = M⁻¹(τ − Cq̇ − g)` | Ch7-9 |

**Ch2 是这条链的"字母表"**（没有姿态表示就写不出 `k(q)`），
**Jacobian 是链条的铰链**（它同时出现在速度、逆解、奇异、动力学四处）。

## Ch2 · 姿态表示 (Orientation)

**重点**

| 表示 | 参数数 | 优点 | 坑 |
|---|---|---|---|
| 旋转矩阵 R | 9 | 复合就是矩阵乘法 | 冗余，6 个约束 |
| 欧拉角 (最小表示) | 3 | 直观、参数最少 | **万向节死锁**；序列 + 内旋/外旋必须说清 |
| 轴角 (θ, r) | 4 | 几何意义最强 | θ=0/π 退化 |
| 单位四元数 {η, ε} | 4 | 无奇异、数值稳、易插值 | 双覆盖 Q 与 −Q 同一姿态 |

**必须刻进肌肉记忆的两条**

- **current frame（绕动轴 / 内旋）→ 依次右乘**：`R = R₁·R₂·R₃`
- **fixed frame（绕定轴 / 外旋）→ 依次左乘**：`R = R₃·R₂·R₁`

Ex 2.1 的"两种描述得到同一个 R"不是巧合，而是这条规则的直接推论：
绕动轴按 xyx 转 (α,β,γ) ≡ 绕定轴按逆序 xzy 转同样的角。

**手算要点**：`arctan` 一定要自己判象限（Ex 2.2 中 `rx<0, ry>0` 要 `+π`）。
代码里全部换成 `atan2`，这也是 `atan2` 存在的唯一理由。

**作用**：给后面每一章提供 `⁰R_i` 这块积木。

## Ch3 · 正运动学 & DH 约定

**重点**

1. **齐次变换** `T = [[R, r],[0,1]]` 把旋转和平移打包，链式相乘即可传递：
   `⁰T_n = ⁰T₁·¹T₂···ⁿ⁻¹T_n`。
2. **DH 约定**把每根杆压成 4 个数 `(l, λ, d, δ) = (a, α, d, θ)`：

   ```
   ⁱ⁻¹T_i = Rot_z(δ)·Trans_z(d)·Trans_x(l)·Rot_x(λ)
   ```

3. **画坐标系四步**（讲义黄字，考试直接考）：
   ① 画关节轴 → ② z 轴沿关节轴 → ③ `x_i = z_{i-1} × z_i`
   （两 z 平行时 x 沿杆延伸方向）→ ④ 填表。
   - `d`：沿 z 量两条 x 轴的距离
   - `l`：沿 x 量两条 z 轴的距离
   - `λ`：绕 x 从 `z_{i-1}` 到 `z_i`
   - `δ`：绕 z 从 `x_{i-1}` 到 `x_i`（转动关节的变量）

**为什么非要 DH**：Ex 3.1 那种"看图硬推三角函数"在 2 自由度还行，
到 UR5 的 6 自由度就完全不可行。DH 把建模变成**填表**，可程序化。
注意 Ex 2.4 的蓝框提醒：那一题**故意不用 DH**，以后一律用 DH。

**作用**：产出 `⁰T_i(q)`，它是后面所有章节的原料——
Ch4 拿它的平移/旋转块做逆解，Ch5 拿它的 `z` 轴和原点拼 Jacobian，
Ch7 拿它算质心位置。

## Ch4 · 逆运动学

**重点**：正解唯一，逆解**可能无解、多解、无闭式**。UR5 一般 8 组解
（肩左/右 × 肘上/下 × 腕翻转）。

三种手段：

- **4.1 解析 · 位置**：把 `⁰T_3` 的第 4 列和目标对应。技巧是
  ① 两式相除消掉公因子解 `q1`；② 两式平方相加消掉 `q2` 解 `q3`；
  ③ 回代 `atan2` 解 `q2`。
- **4.2 解析 · 姿态**：把 `⁰R_3(q)` 和目标欧拉矩阵**逐元素对应**。
  永远用比值形式 `tan q = r_ij/r_kj` + `atan2`，不要用单个 `acos`（丢符号）。
- **4.3 数值**：`q_{k+1} = q_k + α·Jᵀ(q_k)·e_k`。通用，但只给一个解，
  且收敛慢（3 步远远不够，讲义只是演示流程）。

**关键前提：球腕解耦。** 后三轴交于一点 ⇒ 位置只由前 3 轴决定、
姿态只由后 3 轴决定 ⇒ 6 元非线性方程组拆成两个 3 元问题。
这就是 4.1 和 4.2 被分成两题的原因，也是工业机械臂都做成球腕的原因。

**作用**：把任务空间的指令翻译回关节空间——机器人真正"能被指挥"的那一步。

**与 Ch5 的接口**：4.3 里出现的 `J_AP` 就是 Ch5 Jacobian 的位置部分。
换句话说，**Ch4 的数值法其实已经在用 Ch5 的东西了**，Ch5 只是把它讲透。

## Ch5 · 几何 Jacobian、奇异、微分运动学

**重点**

1. **几何 Jacobian**（按关节类型逐列填）：

   ```
   转动 i:  j_GPi = ⁰e_{z,i-1} × (p_E − ⁰r_{i-1,0}),   j_GOi = ⁰e_{z,i-1}
   移动 i:  j_GPi = ⁰e_{z,i-1},                        j_GOi = 0
   ```
   材料全部来自 Ch3 的 `⁰T_i`：z 轴取第 3 列，原点取第 4 列。

2. **奇异 (5.2)**：`det J = 0` 的位形。物理含义是**某个笛卡尔方向瞬间失控**：
   - 数学上 J 掉秩 → 该方向的速度无法产生；
   - 逆过来 `q̇ = J⁻¹v` 会爆炸 → 实机必须加阻尼（`ch56.inverse_differential(..., damping)`）。

   Ex 5.2 的 RRP：`det J_GP = s₂q₃² + c₂q₃l₂ = 0` ⇒ `tan q₂ = −l₂/q₃`，
   即 **肩奇异**——TCP 落在第 1 轴的轴线上，转 `q1` 不改变 TCP 位置。

3. **递归微分运动学 (5.3)**：不组装 Jacobian，直接沿运动链前向传播速度：

   ```
   ⁰ω_i = ⁰ω_{i−1} + (1−ν_i)·⁰R_{i−1}[0,0,q̇_i]ᵀ
   ⁰ṙ_i = ⁰ṙ_{i−1} + ν_i·⁰R_{i−1}[0,0,q̇_i]ᵀ + ⁰ω_i × ⁰r_{i0,(i−1)0}
   ```
   （`ν=1` 移动，`ν=0` 转动）

   **结果必然等于 `J_G(q)·q̇`** —— 这是全课最好的自检，代码里就是这么验的。
   两者的区别只是"组装成矩阵" vs "边走边算"，后者是 Ch8 Newton-Euler 的前身。

**作用**：Jacobian 是**任务空间和关节空间之间的线性化桥**，
它让"速度控制""力控制""可操作度分析""数值逆解"共用同一个对象。

## Ch6 · 解析 Jacobian、旋转 Jacobian、逆微分运动学

**重点**

1. **解析 vs 几何 Jacobian**——这是本章最容易混的概念：

   | | 定义 | 姿态部分的物理量 |
   |---|---|---|
   | 几何 `J_G` | `[ṗ; ω] = J_G q̇` | **角速度 ω**（有物理意义，但不是任何量的导数） |
   | 解析 `J_A` | `[ṗ; Φ̇] = J_A q̇` | **欧拉角导数 Φ̇**（是导数，但依赖所选欧拉序列） |

   桥梁：`J_G = T_A(Φ)·J_A`，其中 `T_A = diag(I₃, J_R(Φ))`。

2. **旋转 Jacobian `J_R(Φ)`（6.2）**：`ω = J_R(Φ)·Φ̇`。推导套路：

   ```
   ∂R(Φ)/∂χ · R(Φ)ᵀ = [∂r_E/∂χ]_×      χ ∈ {φ, θ, ψ}
   ```
   对每个欧拉角求导、右乘 `Rᵀ`、从反对称阵里 vee 出一列。
   **`J_R` 奇异（det=0）就是万向节死锁** —— 这解释了 Ch2 说欧拉角"有奇异"到底奇异在哪。
   注意 6.2 的求导要**保持顺序**：`dR_z/dφ·R_y·R_x·R_xᵀ·R_yᵀ·R_zᵀ` 中间的项两两抵消，
   这正是能得到简洁结果的原因。

3. **逆微分运动学（6.3）**：五步循环
   `k(q) → e = K(p_d − p) → q̇ = J_Aᵀe → q = q + Δt·q̇ → 判收敛`。
   和 4.3 是**同一个算法**，只是把步长 `α` 解读成积分步长 `Δt`。
   加权矩阵 `K` 用来给不同方向不同优先级（比如位置比姿态重要）。

**作用**：Ch5 给"速度怎么算"，Ch6 给"速度怎么反过来用"，
并把姿态的时间导数问题（`ω` vs `Φ̇`）彻底说清楚。

## Ch7 / Ch8 / Ch9 · 动力学（作为运动学的下一层）

统一方程：`τ = M(q)q̈ + C(q,q̇)q̇ + g(q)`

- **Ch7 Lagrange（能量法）**
  `M(q) = Σᵢ [ mᵢ J_PᵢᵀJ_Pᵢ + J_Oᵢᵀ (⁰RᵢIᵢ⁰Rᵢᵀ) J_Oᵢ ]`
  ← **这里 Ch5 的 Jacobian 被直接回收**，只不过算的是"质心的 Jacobian"。
  `C` 由 Christoffel 符号 `Γ_ijk = ½(∂m_ij/∂q_k + ∂m_ik/∂q_j − ∂m_jk/∂q_i)` 得到；
  `g` 由质心位置对 q 求偏导得到。
  优点：结构清晰、直接给出 M/C/g，适合控制设计与参数辨识。缺点：符号量爆炸。

- **Ch8 Newton–Euler（递归法）**
  前向递推 ω、ω̇、r̈（**Ch5.3 递归公式的加速度版**），后向递推力 f 与力矩 μ。
  `O(n)` 复杂度，实时控制的标准做法。
  两个实用技巧：① 把基座加速度设成 `[0,0,+9.81]` 让重力自动混入惯性力；
  ② 最后只取 z 分量，**手算时只需算矩阵第 3 行**。

- **Ch9 正/逆动力学**：同一个方程两个方向。
  逆动力学 `(q,q̇,q̈) → τ` 用于前馈/力矩规划（Newton–Euler 最快）；
  正动力学 `(q,q̇,τ) → q̈ = M⁻¹(τ − Cq̇ − g)` 用于仿真。
  `demo` 里验证了 Lagrange 与 Newton–Euler 给出**完全相同**的 τ，
  以及 `forward_dynamics ∘ inverse_dynamics = 恒等`。

## 章节联动图

```
        Ch2 姿态表示  ── 提供 R ─────────────┐
                                            ▼
        Ch3 DH + 正运动学  ⁰T_i(q) ──────────┬─────────────┐
                │                            │             │
     取平移/旋转块│                    取 z 轴 & 原点│      取质心位置│
                ▼                            ▼             ▼
        Ch4 逆运动学 ◄───── 用 Jᵀ 迭代 ── Ch5 几何 Jacobian   Ch7 M(q)
         (4.1/4.2 解析)                       │  │              │
         (4.3 数值)                           │  └─ det J=0 ─► 5.2 奇异
                ▲                             │                 │
                │                     5.3 递归速度 ── 加一次导 ──┴─► Ch8 前向递推
                │                             │
                └──── 6.3 逆微分 ◄── Ch6 J_A、J_R(Φ)、J_G = T_A·J_A
                                              │
                                     Ch9 正/逆动力学（Ch7 ≡ Ch8 的两条路）
```

**三条最值得记住的"跨章等式"**（也是最好的自检）：

1. `递归速度传播 (5.3) == J_G(q)·q̇ (5.1)`
2. `J_G == T_A(Φ)·J_A`，其中 `T_A = diag(I, J_R(Φ))` (6.1 + 6.2)
3. `Lagrange τ (Ch7) == Newton–Euler τ (Ch8)`，且 `正动力学 ∘ 逆动力学 = I` (Ch9)
